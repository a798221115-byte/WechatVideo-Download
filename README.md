# 视频号下载助手

一个本机自用的微信视频号页面内批量下载助手。它通过 Electron 托盘程序、本地控制台和 Mockttp 本机代理，在微信桌面端视频号页面里注入多选工具条，方便把“赞和收藏”等页面里的视频加入本地下载队列。

> 仅建议下载你自己有权保存的内容。请遵守微信视频号平台规则、版权要求和当地法律。

## 功能

- 在微信桌面端视频号页面内显示多选框。
- 支持页面工具条：扫描、全选本页、反选、清空、自动采集、加入下载。
- 工具条支持收起、展开和拖动到任意角落。
- 本地控制台显示等待、下载中、完成、失败任务。
- 完成任务支持直接打开所在文件夹。
- 默认保存路径：`downloads/<author>/<date>_<title>_<videoId>.mp4`。
- 启动代理时会生成本机唯一根证书，不内置共享证书或私钥。
- 默认无云端同步、无自动更新、无遥测。
- 如果启动前已经有系统代理，例如 v2rayN 的 `127.0.0.1:10808`，助手会继续把上游请求转发到该代理，避免破坏 VPN 链路。

## 当前限制

- 第一版主要面向 Windows 微信桌面端。
- 视频号列表卡片通常不直接暴露真实视频地址。为了避免下载错视频，助手只在能明确匹配“所选卡片”和“捕获到的视频地址”时加入下载。
- 如果页面提示“没匹配到这个卡片的视频地址”，请先点击该卡片播放几秒，再回到列表勾选并加入下载。
- 加密视频和部分动态接口仍可能因视频号页面变化而需要继续适配。

## 安装和运行

### 方式一：源码运行

要求：

- Windows
- Node.js 20 或更新版本
- npm

```bash
npm install
npm start
```

启动后会打开本地控制台：`http://127.0.0.1:20250/`。

### 方式二：打包 Windows exe

```bash
npm install
npm run icon:build
npm run package:win
```

打包结果会生成在：

```text
dist/<timestamp>/视频号下载助手-win32-x64/WxChannelHelper.exe
```

`dist/` 不提交到 GitHub，建议自己本机打包，或后续在 GitHub Releases 上传构建好的压缩包。

## 使用方法

1. 启动 `WxChannelHelper.exe` 或运行 `npm start`。
2. 在本地控制台点击“启动代理”，或通过托盘菜单启动代理。
3. 重新打开微信桌面端的视频号页面。
4. 进入“赞和收藏”等页面。
5. 页面底部会出现工具条：
   - `扫描`：尝试扫描页面内已加载的视频数据。
   - `全选本页`：选择当前可见卡片。
   - `反选`：反选当前可见卡片。
   - `清空`：清除所有勾选状态。
   - `自动采集`：自动滚动页面采集更多卡片。
   - `加入下载`：把已匹配到视频地址的选中卡片加入本地下载队列。
6. 如果提示没有匹配到视频地址，先点击该视频卡片播放几秒，再返回列表重新加入下载。
7. 下载完成后，在本地控制台点击“打开文件夹”查看文件。

## 托盘菜单

- `Start Proxy` / `Stop Proxy`：启动或停止本机代理。
- `Open Console`：打开本地控制台。
- `Open Downloads`：打开下载目录。
- `Restore Proxy`：恢复启动前的系统代理设置。
- `Quit`：退出程序并恢复代理。

## 安全设计

- 代理和控制台只监听 `127.0.0.1`。
- 根证书在本机生成并安装到当前用户证书库，不使用内置共享证书。
- 退出时会尝试恢复启动前的 Windows 系统代理。
- 下载记录只保存任务状态、标题、作者、视频 ID、来源和本地路径。
- 对 `token`、`key`、`exportkey`、`pass_ticket` 等敏感 URL 参数做日志脱敏。
- `data/`、`downloads/`、`logs/`、`dist/`、`node_modules/` 默认被 `.gitignore` 排除。

## 常见问题

### 开了 VPN 后视频号打不开

如果你使用 v2rayN、Clash 等代理工具，建议先启动 VPN，再启动本助手。助手会读取启动前的系统代理，并把它作为上游代理继续转发。

如果网络异常，可以：

1. 点击本地控制台的“停止代理”。
2. 确认 v2rayN 是否恢复到原来的系统代理。
3. 再点击“启动代理”。
4. 重新打开微信视频号页面。

### 为什么提示“没匹配到这个卡片的视频地址”

因为列表页里的卡片通常只有封面和标题，没有真实 mp4 地址。助手需要在你点击该卡片播放时捕获视频地址，然后把地址绑定回这张卡片。为了避免下载错视频，匹配不明确时不会强行下载。

### 为什么不是我选哪个就一定能下哪个

视频号页面会动态加载和加密部分资源。当前版本优先保证“不下错”，如果无法明确匹配，会提示你播放后再加入下载。

```text

public/         本地控制台页面
tests/          单元测试
scripts/        图标生成、构建检查、Windows 打包
assets/         应用图标
```
